# SkyPost Bot (poster-bot)

Telegram-бот для публікації в канали: пости, контент-план, копіювання, mirror, billing.

## Запуск

```bash
python3 -m venv myenv
source myenv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заповніть змінні
python main.py
```

Або `./start_bot.sh` (після налаштування venv).
